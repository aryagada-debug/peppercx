## Database changes (one migration)

New tables, all with RLS scoped to `auth.uid() = user_id`:

- `**user_quotas**` — `id, user_id, period_type ('month'|'quarter'|'year'), period_start, period_end, target_amount, created_by, created_at, updated_at`. Closed amount and weighted pipeline computed at read time from `staffing_deals` (won deals where `vsd`/`bopm` = the user).
- `**user_notifications**` — `id, user_id, type, actor_name, actor_avatar_url, body, source_entity_type, source_entity_id, source_entity_name, read, created_at`. Realtime-enabled.
- `**smart_nudges**` — `id, user_id, type, text, target_entity_type, target_entity_id, target_entity_name, primary_action_label, primary_action_payload jsonb, confidence, generated_at, expires_at, dismissed, snoozed_until`. Generated by edge function, dismissed/snoozed by user.
- `**user_recent_views**` — `id, user_id, entity_type, entity_id, entity_name, viewed_at`. Upsert on visit; auto-prune via simple LIMIT in query.
- `**user_pins**` — `id, user_id, entity_type, entity_id, entity_name, pinned_at`. Unique on (user_id, entity_type, entity_id).
- `**user_nudge_settings**` — `user_id, type, enabled` (per-type mute).

Realtime: enable for `user_notifications`, `smart_nudges`, `deal_rgy_weekly` (already used), `slack_inactivity_nudges`.

## Edge function

- `**generate-smart-nudges**`: scheduled + on-demand (called by the "Refresh" button, rate-limited to 1/min/user). Uses Lovable AI (`google/gemini-3-flash-preview`) to summarize signals into 3–8 nudge tiles per user. Inputs: user's deals + recent RGY flags + slack inactivity rows + meetings without prep + stale deals (no activity > 10d). Output written to `smart_nudges` table. Tool-calling for structured output.
